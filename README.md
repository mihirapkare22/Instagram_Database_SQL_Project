# Instagram_Database_SQL_Project

The Instagram Database Management System is a relational SQL database project designed to model the core data and relationships of an Instagram-like social media platform.

The database manages users, followers, posts, comments, reactions, post media, filters, effects, tagged users, and post types. The project demonstrates how a normalized relational database can be used to organize social-media data and maintain relationships between different entities.

🎯 Project Objective

The main objective of this project is to design a structured SQL database that can efficiently store and manage Instagram-style user and post information while supporting relationships such as following, commenting, reacting, tagging users, and applying filters/effects to media.
